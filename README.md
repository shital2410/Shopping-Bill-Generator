# Shopping Bill Generator

A Python-based command-line application that automates the generation of formatted shopping bills. This project is designed to accept product details (name, quantity, and price) and generate an itemized receipt including subtotal, discount, tax, and the final payable amount.

## Features
- **Itemized Billing:** Input multiple product names, quantities, and individual prices.
- **Automated Calculations:** Automatically handles subtotal, discount rates, taxes, and the final grand total.
- **Clean Layout:** Displays a neatly structured and easily readable receipt format.

## Technical Concepts Used
- **Data Structures:** Lists and Dictionaries to store and manage structured product records.
- **Control Flow:** Loops for item iteration and handling user inputs.
- **Modular Code:** Separated functions for distinct tasks like discount and tax calculations.
- **Validation:** Handles invalid quantities and numerical values smoothly.

## Technologies Used
- Python 3.x

## How to Run the Project

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project directory:**
   ```bash
   cd shopping-bill-generator
   ```

3. **Run the application:**
   ```bash
   python main.py
   ```
